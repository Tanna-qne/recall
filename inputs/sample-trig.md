# 示例：三角函数基础

在直角三角形中，设锐角为 θ，对边为 a，邻边为 b，斜边为 c。
正弦 sinθ = a/c，余弦 cosθ = b/c，正切 tanθ = a/b。
勾股定理：a² + b² = c²。
由勾股定理可得同角关系：sin²θ + cos²θ = 1，并且 tanθ = sinθ / cosθ。

弧度制：一个完整的圆是 2π 弧度，等于 360°。所以 180° = π 弧度，1 弧度约等于 57.3°。

特殊角的值：
sin30° = 1/2，cos30° = √3/2，tan30° = √3/3。
sin45° = cos45° = √2/2，tan45° = 1。
sin60° = √3/2，cos60° = 1/2，tan60° = √3。

诱导公式（常用的几条）：
sin(π − θ) = sinθ，cos(π − θ) = −cosθ。
sin(−θ) = −sinθ，cos(−θ) = cosθ。
sin(π/2 − θ) = cosθ，cos(π/2 − θ) = sinθ。

和角公式：
sin(α + β) = sinα cosβ + cosα sinβ。
cos(α + β) = cosα cosβ − sinα sinβ。
二倍角：sin2α = 2 sinα cosα，cos2α = cos²α − sin²α。
